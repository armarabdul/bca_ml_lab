# Naive Bayes Document Classification

## Program
Use the Naive Bayes classifier to classify documents and calculate:

- Accuracy
- Precision
- Recall

## Files

- `naive_bayes_document_classification.py` — Python program
- `data.csv` — sample document dataset

## Install

```bash
pip install pandas scikit-learn
```

## Run

```bash
python naive_bayes_document_classification.py
```

## Concepts Used

1. CountVectorizer — converts document text into numerical features.
2. Multinomial Naive Bayes — performs document classification.
3. Accuracy — measures overall correct predictions.
4. Precision — measures how many predicted positive documents were actually positive.
5. Recall — measures how many actual positive documents were correctly identified.
